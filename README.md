## 🔧 Core Capabilities

### 🌐 AI-Powered Productivity, Locally
- ⚡ **Offline-Compatible**: Utilize open-source models like GPT4All, Mistral, and others with no network required  
- 🧩 **Switchable AI Engines**: Choose the best model for writing, coding, research, or chat  
- 🎛️ **Tunable Response Style**: Adjust settings like creativity, temperature, and repetition control

### 📂 Enhanced File Handling
- 📄 **Document Integration**: Drop in PDFs, TXT, or MD files for AI summarization or Q&A  
- 🧠 **Session Memory**: Retain context for meaningful, multi-turn dialogues  
- 📌 **Custom Prompt Storage**: Save and reuse your best input formats  
- 🎓 **Knowledge Toolset**: Tackle math, history, science, and legal concepts with depth

### 👨‍💻 Built for Developers
- 💬 **Code Generation & Explanation** – From scripts to snippets, get reliable help in seconds  
- 🛠 **Command Line Helper** – Turn natural language into shell commands  
- 🔍 **Regex & SQL Builder** – Generate and understand complex patterns or queries  
- 🧷 **Code Editor Integration** – Easily sync with external environments like VS Code

### ✍️ Creative & Accessible Interface
- 🎙️ **Voice Input & Playback** – Dictate your messages and hear them spoken aloud  
- 🌗 **Light/Dark Mode Ready** – Customize the appearance to your liking  
- ✏️ **Built-in Markdown Pad** – Craft structured content and export with ease  
- 🌐 **Multilingual Support** – Translate and rephrase across more than 20 languages
